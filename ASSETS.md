The character composition (zoom, position, motion strength) is saved in `localStorage`. `lappland-tavern-player` schema v2 stores audio and cover Blobs by file fingerprint separately from the v1-compatible library metadata. Object URLs are recreated on startup and released when replaced or cleared. Quota failures fall back to session playback with reimport status; metadata can fall back to localStorage. JSON exports exclude binary files. Full binary backups are not implemented.

Persistent-storage protection is requested on audio import and can be requested again in the cellar settings. It is browser-controlled, not guaranteed: see [MDN StorageManager.persist](https://developer.mozilla.org/en-US/docs/Web/API/StorageManager/persist). Clearing site data still removes the local library. Use the same origin (`http://127.0.0.1:5173`) and retain original music files.

## Libraries and Publishing

UI icons use lucide-react (ISC); Three.js (MIT) and other dependencies retain their package licenses. Fonts are OFL (see above), bundled locally; no remote font request. The music-note icon labels an unconnected Spotify feature; a real integration must follow Spotify branding requirements.

Git ignores audio, private artwork, env files, screenshots and build output. Vite still copies all of public into dist, even ignored files. Keep personal assets outside public and inspect build contents before any future deployment. The authorized PNG is intentionally included in normal builds. No deployment is configured.
